# 블로그 작성용 구성과 문장 초안

제목 예시: **MindMate 2차 개발 — 기억을 매번 정리해야 할까? 저장 주기와 모델을 비교해 봤다**

## 1. 만들고 싶었던 대화 경험

“MindMate가 대화를 다시 시작할 때마다 사용자를 처음 만난 것처럼 반응하지 않기를 바랐다. 이전 대화의 선호와 진행 상황을 이어가는 경험을 위해 원문 저장, 사실 추출, 기존 기억 갱신, 기억팩 구성으로 이어지는 구조를 만들었다.”

첫 그림은 실제 기억 시스템의 WRITE/READ 흐름을 보여준다. 대화 모델과 기억 저장 모델이 서로 다른 역할이라는 점을 설명한다.

## 2. 작동은 하지만 비용을 따져볼 필요가 있었다

“초기에는 대화가 끝날 때마다 저장 파이프라인을 실행했다. 짧은 대화가 여러 번 끊기면 추출과 비교 작업도 여러 번 실행된다. 그래서 정리를 조금 미뤄도 대화를 이어갈 수 있는지, 더 저렴한 저장 모델을 써도 되는지 확인하고 싶었다.”

## 3. 원문을 잠시 붙이는 방식도 공짜는 아니다

P1/P3/P5 표를 보여준다. 저장 호출을 줄이는 대신 원문 재입력이 늘어난다는 양쪽 비용을 설명한다. 직접 대화 비용은 이번 질문의 범위에서 제외했다고 명시한다.

## 4. 대화 데이터와 정답부터 고정했다

[10세션 원문](../data/README.md)을 링크하고 날짜 변경·상태 종료·취향 비교·미정 정보 사례를 소개한다. 합성 데이터라는 점, 실제 1년치 대화를 대표하지 않는다는 점을 바로 적는다.

## 5. 어떻게 물어보고 채점했나?

같은 답변 모델, 검색 없음, 빈 초기 기억, 질문 비저장, 시점별 정답을 설명한다. 최종24문항과 중간66문항을 별도로 보고, 자동 점수와 보정을 구분한다. 특정 모델의 출력 자체를 정답지로 삼은 실험이 아니다.

## 6. 결과: 비용은 줄었지만 세부 오답을 봐야 했다

[요약표](../README.md#핵심-결과)와 [최종 문항별 표](../results/final_matrix.md)를 넣는다. mini P1은 보정20/24, 5.5 P1은21/24였고 비용 추정은 약71.5% 낮았다는 관측을 설명한다. 모델·프롬프트·출력한도가 다른 조건임을 표 바로 아래에 적는다.

## 7. 실험 과정에서 발견한 문제

출력 한도를 추론이 모두 소모한 사례, 날짜 필드 때문에 팩에서 제외된 사례, ‘모른다’ 답변의 오채점을 소개한다. 출력 상한100000은 매번100000토큰을 소비한다는 뜻이 아니며, 추론은 출력 토큰에 포함된다고 설명한다.

## 8. 실제로 무엇을 바꾸었나?

“운영에서는 저장 모델을 mini로 바꾸되, 매 세션 저장은 유지했다. 비용 절감 효과를 얻으면서 기존 동작과 비교하기 쉬운 변경부터 적용한 것이다. 묶음 저장과 로컬 모델은 후속 검증으로 남겼다.”

## 9. 다음 실험

다양한 길이·여러 시나리오·반복 실행, 원문량 기반 정리 시점, 검색 개선, 로컬 모델 출력 계약을 다룬다. 이번 결과를 전 사용자에 대한 확정 성능으로 확대하지 않는다.

## 글에 붙일 짧은 실험 조건

> 동일 합성 대화10세션 · 조건별1회. GPT-4o 답변·자동 채점 후 기록된 오채점 보정 반영. 저장 모델별 프롬프트·출력 한도 차이 포함. 비용은 정상 저장 API 실측 + 평가용 세션 시작 입력 추정이며 직접 대화·음성·평가·실패 비용 제외.

## 혼동하기 쉬운 표현

| 피할 표현 | 자료에 맞는 표현 |
|---|---|
| mini와5.5의 성능은 같다 | 이 시나리오의 P5에서는 최종 정답 수가 같았다 |
| 운영비가 항상74% 감소 | 이 실험의 P5 운영 비용 추정이 약73.6% 낮았다 |
| 원문은 내 실제1년치 대화다 | 사용자와 설계한10세션 합성 대화다 |
| 정답률은 저장 모델만의 능력이다 | 저장·선별·팩·고정 답변 모델을 거친 시스템 결과다 |
| GPT-6 Astra가 최종 채점했다 | GPT-4o 자동 점수에 기록된 검토·사용자 승인 보정을 반영했다 |
| 로컬 Qwen 성능이 나빴다 | 연동·출력 문제로 본 비교에서 제외했으며 재검증이 필요하다 |

이 문서는 글의 초안 재료다. 원문 데이터와 실제 평가 결과는 각각 data/와 results/에 독립적으로 보존되어 있다.
